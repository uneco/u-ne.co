# Third-party package references

Prepared on 2026-09-05. This directory documents third-party libraries and fonts included in Carpenter; it does not assign a license to the Carpenter application.

[packages.json](packages.json) records the installed versions, package repository metadata, copied license filenames, and their SHA-256 hashes. License texts were copied without alteration from the installed runtime and font packages.

The package references cover React, React DOM, Scheduler, Jotai, Earcut, Lucide React, vgpu and its runtime packages, wgpu-matrix, DM Sans, and Noto Sans JP. The corresponding license texts are linked from [the license page](index.html).
